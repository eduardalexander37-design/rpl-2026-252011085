## Deskripsi Repository

Repository ini dibuat sebagai bagian dari tugas mata kuliah Rekayasa Perangkat Lunak untuk mendokumentasikan proses pembelajaran dan membangun kebiasaan kerja yang terstruktur dalam pengembangan perangkat lunak. Repository ini berisi dokumen mengenai komitmen kerja, panduan kontribusi, kebijakan penggunaan Artificial Intelligence (AI), lisensi, serta laporan tugas dalam format PDF.

## Tujuan Belajar

Tujuan saya mempelajari Rekayasa Perangkat Lunak adalah memahami tahapan pengembangan perangkat lunak, mulai dari analisis kebutuhan, perancangan sistem, implementasi, pengujian, hingga pemeliharaan. Selain itu, saya ingin mempelajari penggunaan Git dan GitHub untuk mengelola perubahan kode, mendokumentasikan pekerjaan, serta berkolaborasi dengan anggota tim secara efektif.

## Daftar Isi Repository

Repository ini terdiri dari beberapa file utama. File `README.md` berisi identitas mahasiswa, tujuan belajar, deskripsi repository, dan catatan keputusan teknis. File `KOMITMEN_KERJA.md` menjelaskan komitmen saya dalam berkomunikasi, mengatur waktu, bekerja sama, dan menyelesaikan tugas. File `CONTRIBUTING.md` berisi panduan bagi orang lain yang ingin berkontribusi melalui branch, commit, dan pull request. File `AI_POLICY.md` menjelaskan aturan penggunaan AI secara etis dan cara memverifikasi hasilnya. File `LICENSE` berisi ketentuan penggunaan dan distribusi materi dalam repository. Folder `tugas-01/` digunakan untuk menyimpan laporan tugas dalam format PDF.

## Catatan Keputusan Teknis

Keputusan teknis yang saya ambil adalah menggunakan MIT License untuk repository ini. Saya mempertimbangkan MIT License dan GNU General Public License (GPL). MIT dipilih karena memiliki ketentuan yang sederhana dan memungkinkan orang lain menggunakan, mempelajari, serta memodifikasi materi dengan tetap menyertakan pemberitahuan hak cipta dan lisensi. Sementara itu, GPL lebih sesuai apabila tujuan utama repository adalah memastikan karya turunan yang didistribusikan tetap menggunakan lisensi GPL. Karena repository ini berfokus pada dokumentasi dan pembelajaran, MIT dianggap lebih sesuai dengan tujuan penggunaan ulang materi secara mudah.
